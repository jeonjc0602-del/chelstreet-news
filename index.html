어떤 단어가 들어가면 알림이 오나요?

첼시 전용 피드(BBC·가디언·football.london·팬 블로그·FotMob 등)는 전부, 나머지 매체는 제목에 "Chelsea"나 "첼시"가 들어간 기사만 가져와요. 같은 기사가 여러 곳에 올라오면 하나만 보여요. 전체 뉴스 탭에는 이 기사가 다 나오고, 키워드 뉴스 탭과 알림에는 위 단어가 하나라도 있으면 분류해서 보여 주고, 여러 개가 겹치면 오피셜 → 부상 → 이적 → 인터뷰 → 프리뷰/분석 순으로 하나만 붙어요. FotMob 글 중 어디에도 안 걸리는 건 프리뷰/분석으로 모아요.
